# Логические задачки

Сайт с логическими задачками для тренировки ума в любом возрасте.

Здесь лежат готовые файлы сайта: их не нужно собирать, изменять или
устанавливать что-либо — GitHub Pages покажет их как есть.

Как пользоваться: откройте адрес сайта, придумайте себе имя
и приступайте к задачам.

Все задачи работают на самом телефоне: история занятий и настройки
хранятся на устройстве, а в общей базе видны только придуманное имя,
рисованная картинка и число решённых задач.
